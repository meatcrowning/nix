# apps/ — vendored desktop applications

This tree contains the standalone Qt/QML applications and the shared Python/QML
helpers they use. It is vendored source, not a Nix module. Before changing any
appearance, read ../docs/DESIGN.md; that document owns the desktop's palette,
typography, spacing, motion, chrome, menus, controls, drop feedback, and
honesty-of-controls rules. This guide owns implementation mechanics. Read the
nearest app guide before editing an app; the app guide wins for app-specific
details.

## Packaging, defaults, and source layout

home/default.nix and sys/default.nix recursively import every .nix under their
trees through umport. Keep applications outside home/ and sys/: putting one
there would evaluate its own files (including a possible flake) as NixOS
modules. Nothing under apps/ is imported by Nix evaluation.

Each home/prog/<app>.nix wrapper executes the live source at
/home/lam/nix/apps/<app>/main.py on both machines. .py and .qml edits therefore
need no rebuild, but these apps have no hot reload: relaunch the app to observe
them. A rebuild is needed for a dependency or packaging change; do not relaunch
a user's running app on their behalf. Every wrapper has an air branch that uses
book's /usr/bin/python3 rather than a Nix interpreter.

Dependencies must work on both top and book: adding a package only to the Nix
pyEnv does not affect the air branch. Add the Fedora python3-* dependency too,
or degrade cleanly; a genuinely machine-specific dependency must be called out.
See the root guide's “Both machines by default” rule.

The default associations are deliberately centralized in
home/prog/mime-defaults.nix; each app's .desktop entry and field codes are
generated by its own package module. Current defaults are filer for directories,
viewer for every type in its IMAGE_EXTS/VIDEO_EXTS, reader for Markdown, surfer
for HTML/XHTML and x-scheme-handler/http(s)/about, and player for every type in
its AUDIO_EXTS. Keep viewer's MIME list and extension lists synchronized.
Editor is eligible for text/source types but is default for none; painter,
goetia and updater intentionally declare no MIME type. An app may claim only a
type it can actually open (player's %F path handling is documented in
player/AGENTS.md).

The file picker is separate from MIME defaults: filer implements the
org.freedesktop.impl.portal.FileChooser backend in filer/portal.py and
filer/pick.py, packaged by home/prog/filer-portal.nix, and it ships dormant.
Use filer-portal-switch on|off; see filer/AGENTS.md.

## pylib/: shared Python contracts

Apps insert HERE.parent / "pylib" into sys.path; deeper tools use the
corresponding parent path. Move the apps/ tree as a unit. Shared helpers have
one owner and one implementation; do not fork their algorithms into an app.

- lastfm.py is the sole Last.fm client and credential owner. Credentials are in
  ~/.config/lastfm/account.json (or $LASTFM_CONFIG, mode 0600), never in this
  public repo. It is stdlib-only; GUI callers must use worker threads or their
  own QNetworkAccessManager, never blocking urllib on the GUI thread. Missing
  credentials are an inert, explanatory feature. Scrobbles queue in
  ~/.local/state/lastfm/scrobble-queue.json, retry until Last.fm's 14-day limit,
  and paging callers must handle a one-row bare object. Connect with
  apps/player/tools/lastfm-connect.py --keys KEY SECRET, then the same tool
  without arguments (or the player's settings button). Test with
  apps/player/tools/lastfm-test.py.
- handoff.py is the Qt-free AF_UNIX handoff between already-running apps. Try it
  before importing PySide6; refusal is normal when the target is not visibly
  exposed. Listen before clearing a socket and call removeServer() only when
  nothing is accepting. Viewer/file-browser return selection through the
  per-process/per-pane --select-back socket. Use the handoff, select-back, and
  viewer-select harnesses under apps/{pylib,viewer,filer}/tools/.
- vtbclient.py is the only app-side hyprvtb bridge. Its module docstring is the
  authoritative wire protocol; do not restate it. Non-default registration
  flags must be included in the same REGISTER write and replayed on reconnect;
  add new flags to _flag_lines_locked() and the setter. Test with
  apps/pylib/tools/vtb-register-test.py.
- trackmatch.py is the sole artist/title normalizer; use it for song identity.
- pngmeta.py reads/writes PNG text chunks: painter writes painter, filer reads
  it plus prompt, workflow, and cte_*; use read_text_path() when pixels are
  unnecessary. mp4meta.py handles mdta in moov/udta/meta and must patch every
  stco/co64 offset when growing moov; it is stdlib-only, with no ffmpeg, and
  runs in the download callback.
- boorutags.py and data/danbooru-tags.csv.gz are the shared Danbooru
  vocabulary. Look up tags rather than inventing them; storage uses underscores
  and prompts use spaces. Build its search index off the GUI thread and retain
  the bounded scan/ranking behavior. Painter's anima-test.py covers the seam.
- clipfile.py is the only file clipboard implementation. Run it as a process;
  it stays alive as the Wayland data-control owner. --image adds an image MIME
  while retaining file offers, and --image-only offers exactly one supported
  image and no path. Do not replace it with QClipboard or wl-copy; the protocol
  requires zwlr_data_control_manager_v1/ext_data_control_manager_v1. Test in
  apps/pylib/tools/clipfile-test.sh.
- deskstyle.py is the one channel for desktop-wide fontFamily, fontSize,
  reduceMotion, animSpeed, and scrollbarStyle. Read the panel's
  ~/.config/quickshell/settings.json (or $DESK_SETTINGS in an offscreen
  harness), install DeskStyle before loading Theme.qml, and keep a Python
  reference. animSpeed accepts any finite value > 0, otherwise 1.0.
- kdetheme.py selects the theme source: wallpaper palette under Hyprland and
  generated ~/.cache/deskstyle/kde-Theme.qml from kdeglobals under Plasma.
  Use Palette(theme_source(PANEL_THEME)); do not branch in Theme.qml or
  components. DESK_SESSION=plasma|hypr and DESK_KDEGLOBALS let harnesses select
  a session/scheme. kde_chrome() is only for surfer's web re-skin;
  chantheme.py, twittertheme.py, scrollcss.py, userscript.py, and
  vivaldichrome.py generate browser sheets/userscripts and share the loopback
  courier. Keep the courier loopback-only and parameterless. Use
  kdetheme-test.py, chan-userscript-test.py, scrollcss-test.py, and
  vivaldi-theme-test.py; the Vivaldi probe uses its own Xvfb/profile.
- oxygenstyle.py exposes Oxygen metrics only when the session is Plasma and the
  active style is Oxygen; add a setting by updating _KEYS and the deskstyle.py
  property. DESK_OXYGENRC selects a test rc; use oxygen-test.py and
  oxygen-scrollbar-probe.py. Where a real QWidget/QStyle exists, ask it rather
  than copying metrics.
- glyphs.py is the ingestion-time mapping for characters absent from the desktop
  font. Keep it and the panel's Glyphs.qml table in sync. spellcheck.py is the
  sole checker: it invokes hunspell -a; SPELL_HUNSPELL and SPELL_DICPATH are
  Nix-only defaults and book resolves from PATH and /usr/share/hunspell. A
  missing dictionary means available=false and no markings. Keep its token
  exclusions and shared $XDG_STATE_HOME/spellcheck/personal.dic; use
  spellcheck-test.py.
- imgfit.py is the shared byte-budget encoder: search JPEG quality before
  lowering resolution, sample real alpha, encode to QBuffer, and retain its
  intentional 256-MB Qt decode ceiling. Use the filer image-conversion tests
  and painter collage test. kitty-vtb.py remains stdlib-only.
- warden.py arbitrates the ollama/ComfyUI backends through
  home/srvs/ai-warden.nix. Reserve before loading/queuing, call done() when
  finished, draw a refusal with its reason, and do not duplicate the daemon's
  freeing notification. It fails open on missing, timed-out, or wedged daemon.

## qmlcommon/: shared QML contracts

Import it from an app's QML with import "../../qmlcommon". Theme is a root
context property, so file components see it without another import path.

### Motion and scrolling

Use Motion.qml for every animation. Do not add a duration literal: the slide
duration comes from the generated ~/.local/state/hyprvtb/DeskMotion.qml, whose
fallback must equal plugin:hyprvtb:slide_duration_ms in hyprvtb/main.cpp. Use
motion.ms(...) and motion.slideEasing; deliberate non-slide durations must
explain themselves and still use ms(). DeskStyle.reduceMotion and animSpeed are
applied there. Motion is read at app construction; relaunch is required.

Never add a bare ListView, GridView, Flickable, or ScrollView. Use the
corresponding Kinetic* type. Qt flicking is off; WheelScroll consumes the
compositor's proportional high-resolution stream without adding momentum. Keep
the overlay behind content (z: -1) so nested wheel handlers receive events; the
view's optional wheelLines, wheelStep, wheelEnabled, surfer-only wheelGain, and
onWheelScrolled remain available. Python wheel handling uses pylib/kinetic.py
(DETENT, ANGLE_PER_PIXEL, WHEEL_GAIN, is_wheel_detent()), never copied
constants. viewer/qml/ImageViewer.qml is the documented exception because its
zoom handler consumes every wheel event. Surfer's ZoomFilter requires
wheelGain: WheelGain on all its scrollable overlays. If momentum is absent,
inspect the plugin:hyprvtb:kinetic setting and host configuration; hyprctl reload
clears runtime kinetic_set(true).

SpellMarks.qml is the only spelling renderer. Place it beside the text item,
with a real visible viewport; use menuItems() in the existing CtxMenu and
replaceFn for one-step undo. It belongs to editor prose and painter prompts,
not path/find/password/numeric fields; goetia's inbox follows board/AGENTS.md.

CtxMenu.qml is canonical; copies in apps must remain byte-equivalent until
removed. It restores the pre-menu focus before running a trigger. Text editors
must use persistentSelection: true and call forceActiveFocus() on the right-press.
SelectButton.qml likewise remains byte-equivalent in player and filer.

### Plasma chrome and shell

DeskMenuBar.qml is the Plasma replacement for the hyprvtb titlebar column. Use
the same tbButtons array and action function for both faces, annotate entries
with menu:/menuSep:, anchor content below the bar, and keep its height zero
outside Plasma. A button's tooltip is its full menu label; state 1 is active and
2 disabled. Reparent dropdowns to the top item tree and route row clicks through
root.choose(id). DESK_SESSION=plasma|hypr selects the branch; harnesses asserting
full-window geometry should pin hypr.

Under Plasma, painter/player/chatter use pylib/kdeshell.py: a real
QMainWindow/QMenuBar/QToolBar/QStatusBar with the app QML in an opaque
QQuickWidget, QT_QUICK_CONTROLS_STYLE=org.kde.desktop, and the package's KDE
style/QPA/theme/icon dependencies. Never make that QQuickWidget transparent,
never install an event filter on QApplication, and never use static QMessageBox
helpers; use the modeless DontUseNativeDialog pattern. StyledBackground.qml
paints the cropped Oxygen background. Keep active/inactive window colour groups
synchronized through kwinactive.py/the KWin helper, and redress every
QQuickWidget on ApplicationPaletteChange.

Oxygen's stock action icons are coloured raster art, not palette-aware SVGs.
Use `kdeshell_icons.themed_icon()` for Qt `QAction`s and bind QML controls'
`icon.color` to `palette.buttonText`; these are the two paths that recolour
normal, active and disabled controls with every live wallpaper palette change.

The shell owns menu order and standard actions, puts view toggles (including
Show Menubar/Ctrl+M) in Settings, updates existing QActions in place, and
rebuilds only when action ids change. Keep persistent widget actions when
clearing bars (_clear_bar, not QToolBar.clear()), re-assert overlay toolbars
after restoreState(), preserve toolbar search and dock widgets, and use a
QStackedWidget for status text/progress. Escape literal % in progress text.
Do not connect footerChanged to set_status; the footer is the hyprvtb badge.
Use barText/bar_labels() for labeled toolbars, setIconText for mnemonic
underlines, and guard_typing() to suspend bare-key actions while editing.
bind_chrome refreshes from buttonsChanged; no-vtb apps pass bind_chrome(None)
and publish only their QML actions. toolbar_widget() and dock() must reuse the
app's engine/context and initial properties. Do not use docks merely for
sidebars. About uses the displayed app name while internal paths/settings retain
their source name. select_plasma_files(engine) must be owned by the engine;
variants preserve the original API/layout and never redeclare final properties
or break controlled-value bindings.

VScroll.qml is the only scrollbar. Call sites use ScrollBar.vertical: VScroll {}
and read VScroll.barW for reserved space. It appears only on overflow, remains
fully opaque, reserves its gutter in both states, draws stepper arrows as
geometry, pixel-snaps the thumb, and selects win31/beveled/flat through
DeskStyle.scrollbarStyle.
WheelNotch.qml is for stepping controls, not scrolling: carry sub-notch
remainders and cap one event with maxSteps.

Use NavButtons.qml/NavHistory.qml for side-button history. Accept only
Qt.BackButton and Qt.ForwardButton, act on the focused pane, reassign stacks so
change signals fire, and omit it when an app has no genuine history. The
offscreen regression is filer/tools/nav-test.py. Any rectangle sent to hyprvtb
must be non-zero; guard it in the app even though the plugin also has a fix.

## Verification and test safety

The user performs all visual, animation, and interaction checks. Never open a
test window on the real monitor, take screenshots of the live desktop, drive
the GUI, script hyprvtb Lua actions, or touch focus, pointer, clipboard,
notifications, audio, gamma, or the running browser. Use tools/sandbox.sh
(start, exec, shot, clients, stop) for GUI tests and tear it down in a trap. Use
QT_QPA_PLATFORM=offscreen, remove WAYLAND_DISPLAY and DISPLAY, and assert
QGuiApplication.platformName() == "offscreen"; never use setdefault. Child
processes receive the same environment. Harnesses that need isolation must use
tools/lib/session-guard.sh and never fall through to the user's session.

Never source an app wrapper to borrow its environment. For surfer use
surfer-qtenv:

~~~bash
surfer-qtenv python3 apps/surfer/tools/find-test.py
( eval "$(surfer-qtenv)"; ... )
~~~

For other apps, obtain only the interpreter path from the wrapper, and add a
qtenv helper if repeated use warrants one. Sourcing surfer opens the user's
browser. For board, the wrapper-specific warning and safe commands are in
board/AGENTS.md.

Use qmllint -I <qml import paths> qml/Main.qml; missing import-path messages are
not QML errors. Confirm QtWebEngine/permission/notification details from
plugins.qmltypes, not memory. For app logic, write a headless PySide harness
instead of clicking. The nearest app guide names the focused tests.
